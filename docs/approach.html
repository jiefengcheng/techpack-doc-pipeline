Considered path

Three pipelines in a fixed order. The live demo is a first-pass result. This page is why the solution holds: split the page, handle hard OCR as one method, then translate with factory knowledge — not one model over the whole screenshot.

demo result · spreadsheet · same narrative on GitHub

A screenshot pack has no PDF text tokens. The page is three products: a ruled BOM (text), color artwork (pixels), and a line drawing (geometry). OCR, translation, or layout alone each mix those products. Order is the method.

flowchart TD
  pack[Screenshot pack]
  split[1 Layout split]
  ocr[2 Hard OCR method]
  gloss[3 Domain translation]
  sheet[EN + CN factory sheet]
  pack --> split
  split -->|ruled table only| ocr
  split -->|artwork| crop[Crop. Stop.]
  split -->|drawing| draw[Crop + optional callouts]
  ocr --> gloss
  gloss --> sheet
Pipeline Strength What must not happen
1. Layout / segmentation Three exclusive regions. Detector is interchangeable. Artwork sent to OCR. Table treated as a picture.
2. Difficult OCR One method for unbounded outliers. A catalog of failure cases. A second whole-page pass.
3. Domain translation Glossary and freezes before any model. An LLM rewriting YKK: 316, 97%, or DTM.

1. Reliable layout / segmentation

Decide what kind of thing each region is before anyone reads a glyph. The hard error is applying the wrong tool: OCR on paint, a document parse on stitches, or a text detector that never sees ruling lines.

flowchart TD
  page[Full page image]
  page --> geom[Page geometry]
  geom --> propose[Region proposals]
  propose --> kind{What is this region?}
  kind -->|ruled lines + cell grid| table[Table]
  kind -->|color-rich, not a grid| art[Artwork]
  kind -->|ink on paper, stitches / callouts| draw[Drawing]
  art --> stop[Crop only. Image stays an image.]
  draw --> labels[Crop. Optional callout OCR. Not the BOM.]
  table --> next[Hand the crop to the OCR method]
  • Split before read. Layout is geometry. The contract is three boxes, not a vendor.
  • Artwork never enters the text path. No OCR, no confidence map, no translation.
  • Drawing is not a BOM. Callouts may be read. They do not go through the factory glossary.
  • The table is a grid first. Ruling lines define cells. Text is filled into those cells.

The current demo already shows this split: red = table, blue = artwork, teal = drawing.

2. Difficult OCR cases

Table OCR failures are not a closed list — watermark through a glyph, tiny type, a spanning header, a digit that looks like O, a cell that reads its neighbor. Publishing a case list becomes the next miss. The path is one method: score, mark, same Table VL call, typed lock last.

flowchart TD
  crop[Table crop]
  crop --> grid[Ruling lines → cell geometry]
  grid --> pass1[First-pass cell OCR]
  pass1 --> score[Score every cell]
  score --> overlay[Confidence overlay]
  overlay --> ok{Trusted?}
  ok -->|yes| locked[Locked cell text]
  ok -->|no| mark[User marks the cell]
  mark --> vl[Same Table VL call]
  vl --> still{Still wrong?}
  still -->|no| locked
  still -->|yes| type[Human typed lock]
  type --> locked
  • Geometry is structural. A wrong glyph does not move the cell.
  • Uncertainty is a surface. Green → red on the same cells the factory will read. Silent blanks can be marked.
  • Rescan is the same call. Table VL, promptLabel: table, on a local service. On a Mac: Foundation Models + Core ML.
  • Typed lock is last. Artwork and drawing stay out of this loop.

Not wired in the demo. The live table is still first-pass Vision + line-grid. The HTTP shape is in ARCHITECTURE.md.

3. Ruled table translation with domain knowledge

Same cells, English over Simplified Chinese, without breaking factory tokens. A general translator will rewrite the order: 97%, 5.5 oz, #5, YKK: 316, DTM, CB.

flowchart TD
  cells[Locked BOM cells]
  cells --> freeze[Freeze digits, units, vendor codes]
  freeze --> gloss[Glossary lock]
  gloss --> left{Leftover English?}
  left -->|no| sheet[Same cell: EN over CN]
  left -->|yes| qwen[Qwen residual call]
  qwen --> sheet
  • Glossary first, in-process. DTM → 同色配线, CB → 后中, Swift Tack → 打枪条. Data, not prompt text.
  • Freeze before replace. Digits, units, and vendor codes are copied through. The model never sees them.
  • Residual only. Leftover English is a Qwen call to the same local service as Table VL.
  • Same grid. No reflow. Artwork is not translated.

On the sample pack the glossary lock finishes the sheet: 119 hits, 32 frozen spans, 0 leftover English. Residual Qwen is for the next pack that has unknown prose.
